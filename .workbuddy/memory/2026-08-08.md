## 修复插件设置页图标不显示问题

**文件**: `apps/desktop/src/components/settings/PluginsSettings.tsx`

**问题**: 插件设置页添加插件后，只显示名称和描述，不显示插件图标。

**根因**: `renderPluginIcon` 函数中，inline SVG 图标路径通过 `IconFromSvg` 渲染时，只传了 `className="shrink-0"`，缺少 `text-t2` 颜色类。当 SVG 使用 `fill="currentColor"` 或 `stroke="currentColor"` 时（如 feature-panel-sample 插件），图标会继承无色父元素的文本色，导致不可见。

**修复**（最终方案）:
1. inline SVG 分支改为 `PluginIcon` 组件 + data-URI `<img>` 渲染：
   - 实测确认：该 Tauri webview 中 `dangerouslySetInnerHTML` 注入的 SVG 不绘制，`<img>` data-URI 能渲染
   - `<img>` 中 SVG 是独立文档，`currentColor`/CSS 变量失效 → 编码前用 `getComputedStyle` 读取 `--t2` 实际色值替换 `currentColor`，并订阅 `useAppearanceStore` 在主题切换时重建
   - 渲染前剥离 `<?xml?>` / `<!DOCTYPE>` 头
2. 新增 `.svg` 文件路径的安全兜底 —— 如果 store 未将 `.svg` 路径内联为 inline SVG，退回显示首字母
3. 保持 emoji/文字/ThemeIcon/首字母回退分支不变

**教训**: 这个 Tauri webview 里 `dangerouslySetInnerHTML` 注入 SVG 不绘制，`<img>` data-URI 才可行；`currentColor` 需手动替换为主题色值。
