# 以结构导航与关键词搜索共同召回知识

2026-10-24，选择以树导航与关键词搜索配合完成知识召回。模型可以沿全库主题导航和单份资料的结构索引定位内容，也可以直接搜索原文，再结合上下文判断相关性；不引入向量检索入口。

仅依赖树中的标题与摘要，可能遗漏没有被摘要覆盖的原文内容。关键词搜索为术语、函数名、错误码等提供直接入口，结构导航则提供主题与上下文。采用这一组合，避免将召回完全限制在目录摘要能够表达的范围内。

## 检索与回答分层

检索层返回结构化证据，包括命中的知识页或原文片段、来源、版本、具体位置，以及已知的冲突或待更新状态。回答层根据这些证据组织最终答案。

未选择将检索与回答绑定为一个直接返回自然语言答案的能力。同一套检索能力可以供聊天、Agent 和搜索界面使用，检索与回答也可以分别评估，便于区分召回问题与答案生成问题。此分层不要求用户在界面上分两步操作。

## 有预算的多轮检索

检索允许模型根据已读到的证据继续选择搜索词或目录分支，跨资料追踪线索。程序限制检索轮数与读取量，达到限制时返回已有证据，并说明尚未解决的缺口。

未选择固定单轮流程，以保留依据中间证据继续查找的能力。停止边界由程序约束，不仅依赖模型自行决定，以控制成本与耗时。

默认检索的时间上限为 10 秒，仅计算找到并返回证据的时间，不包含资料建库和最终答案生成。达到上限时返回已有证据与未解决的缺口；实际可完成的轮数及读取量，需要用真实资料和所选模型验证。

## 验收规模

第一版以单 Vault 1,000 份资料作为完整验收规模，样本覆盖短笔记与长文档，使用固定问题同时检查证据质量与检索耗时。

这一规模是验收基准，不设置文件数量硬上限；超过该规模后的表现需要通过测试确认。

## 质量验收

检索层以是否返回足以支持回答的证据作为核心质量标准。预先标注可接受的证据，检查必要内容是否召回、来源版本与位置是否准确，以及冲突和待核验状态是否正确返回。

测试集覆盖事实定位、跨资料综合、新旧观点冲突及资料中没有答案的情况。未选择主要依据最终答案正确率验收检索层，以便分别判断证据查找与答案生成的质量。

具体质量门槛、两类入口的执行顺序、轮数与读取量限制、提前停止的判定，以及具体搜索实现，仍待讨论。
