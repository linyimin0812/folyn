# 知识库以文件为真源，搜索索引与缓存可以重建

> 2026-10-28 起本 ADR 的存储位置结论（生成物存 `<vault>/__kb__/`、随 Vault 携带）由 [ADR-0011](0011-knowledge-storage-in-app-config.md) 取代：生成物改存 `~/.folyn/vaults/<vaultId>/__kb__/`。文件为真源的原则不变。

2026-10-24，选择以文件作为知识库的真源。主题知识页使用普通 Markdown，引用关系、被引用的历史原文、审阅记录等也以文件保存；关键词索引与缓存属于可重建的派生数据。

未选择以数据库作为正文、引用关系和审阅记录的真源，再将 Markdown 作为编辑视图或导出结果。文件真源符合 Folyn 的文件工作方式，支持外部编辑、版本管理及整体迁移；引用与审阅记录仍需明确格式和一致性校验，不能只保存正文。

## 身份与路径分开

每份原始资料和每个主题知识页使用不随文件重命名或移动而变化的稳定标识。路径记录当前位置，引用关联稳定标识与具体版本；标识及路径映射以文件保存并随 Vault 携带。

未选择以文件路径直接作为身份，以免把重命名或移动误认为删除旧知识、创建新知识。内容变化由版本表达，位置变化更新路径映射。

## 分项发布完整版本

批量导入或后台更新时，单份资料或单个知识页完整处理后即可用于检索，无须等待整批完成。更新中的内容继续使用上个完整版本，并标明状态；未完成的正文、引用或索引不对检索发布。

未选择整批处理完成后统一开放，以便资料持续更新和首批内容尽早可用。每次分项发布仍须保证内容、引用与版本一致。

这一存储边界承接 ADR-0007 的证据可携带要求，外部编辑后的引用核验也见 ADR-0007。标识与移动的具体识别规则、引用与审阅记录的具体文件格式，以及多文件写入和版本发布的一致性机制，仍待讨论。
