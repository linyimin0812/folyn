# 保留原始资料与资料索引，同时生成带出处的主题知识页

2026-10-24，在讨论借鉴 PageIndex 思想的知识库能力时，选择同时保留原始资料及其索引，并生成带出处的主题知识页。原始资料承载证据，资料索引帮助定位相关原文，主题知识页承载经过整理的理解；三者在概念上明确区分。

单独建立原文索引无法满足综合整理知识的目标；只保留生成的知识页则不足以支持回到原文核对。采用上述分层，以同时支持知识整理与来源追溯。

## 主题范围

由用户声明知识库目标，AI 在该范围内根据原始资料发现相关主题，并判断补充已有主题知识页还是新建页面。用户无须提前定义完整的主题目录。

未选择对资料涉及的所有主题自由建页，以减少偶然提及的概念不断扩张为知识页；也未选择仅按用户预设目录整理，以保留根据资料自动发现主题的能力。

## 知识库边界

一个 Vault 对应一个知识库，共享知识库目标、原始资料、主题知识页与检索范围。一个目标可以涵盖多个相关主题，不在同一 Vault 内建立拥有各自目标、资料及检索范围的独立子知识库。

采用这一边界以沿用 Vault 已有的数据隔离方式。没有选择在 Vault 内再划分多个独立知识库；需要分别维护独立知识体系时，以不同 Vault 表达。

## 资料收录与变化跟踪

第一版直接支持 Markdown 与纯文本。网页、外部会话等先保存为正文文件，再纳入收录范围；第一版不直接解析 PDF、DOCX、扫描件或图片资料。

由用户选定原始资料文件或目录，形成知识库的收录范围。范围内的新增、修改自动触发处理，无须用户每次重新发起；知识页更新仍遵守 ADR-0006 的审阅边界。

不默认扫描整个 Vault 作为原始资料来源。生成的主题知识页与原始资料区分，不循环收录为新的原始资料。

选择该方式以兼顾用户对资料范围的控制与持续更新。未选择每次手动收录、手动重新处理变化，也未选择自动扫描整个 Vault。

### 增量分析

一份资料新增或变化后，更新该资料的索引，通过已有来源引用定位关联结论，同时通过主题导航与关键词寻找可能受影响的其他知识页，再分析这些更新候选。候选关联本身不表示既有结论已经失效。

未选择每次重新读取全库资料与知识页进行分析。也不能仅沿已有引用查找影响：新资料尚未被引用，仍可能补充或推翻已有结论，需要同时覆盖新内容的主题关联。

增量分析生成的正文改写、删除与冲突处理继续遵守 ADR-0006 的审阅边界。

## 索引组织

全库主题导航与各份原始资料的结构索引分开。主题导航关联主题知识页和相关资料，每份资料保留自己的章节结构，同一份资料可以关联多个主题。

主题导航用于选择相关主题及资料，资料索引用于在原文中定位证据。未选择将知识页和原文片段统一按全库主题树归类，以免主题组织调整牵动原文结构的重排。

### 资料内部分层

优先采用原始资料已有的章节结构。对于没有标题或章节过长的内容，允许模型提出语义分段、标题和摘要，作为索引中的补充分层。

补充分层只存在于索引中，不修改原文；每个节点必须对应真实、可核验的原文范围。未选择仅按原有标题建树并将无标题资料整体作为一个节点，以支持没有良好排版的文本资料。

知识页的共同维护与更新权限见 ADR-0006；被引用原文的版本保留规则见 ADR-0007；结构导航与关键词召回的组合见 ADR-0008。检索调度、索引的具体格式，以及与现有实现的整合方式，仍待后续技术设计细化。
