# 每个知识主题拥有独立的整理上下文

2026-10-26，用户确认一个 Vault 中可配置多个主题，每个主题拥有独立的名称、目标、收录范围和整理结果。问答检索、资料索引、来源引用、待审阅修订及人工删除意图均以该主题为边界。原始资料仍位于 Vault，同一份资料可被多个主题选用。

未选择在共享知识结果上添加多个关注方向。用户需要的是分别配置和持续维护的知识上下文，单纯筛选共享结果不能满足目标与资料范围的独立性。

主题是用户创建的工作区；知识页是该工作区中整理生成、由人与 AI 共同维护的内容。此前文档中的“主题知识页”指后者，不应与用户配置的主题混用。此决策替代 CONTEXT 和初版设计中一个 Vault 共享一个目标与收录范围的假设；ADR-0005 至 ADR-0009 关于原文保留、共同编辑、引用版本、检索和文件真源的原则继续在每个主题内成立。

异步整理与问答必须绑定启动时的 Vault 和主题身份。切换主题不能改变执行中的写入目标，也不能让旧任务的结果进入新主题的界面。主题之间可以复用原始资料，不共享生成结果和待确认编辑。
