# 保留最新原文与所有曾被引用的原文版本

2026-10-24，选择保留原始资料的最新版本，以及所有曾被主题知识页引用的原文版本。引用应能确定它所依据的原文版本；即使来源后来修改或删除，仍能核对知识形成时的证据。

只保留最新版本不足以支持历史出处核对，保存所有历史版本又会保留从未被引用的中间修改，因此采用按引用保留历史版本的边界。保留历史证据不表示旧结论仍然有效；知识页的修订继续遵守 ADR-0006 的审阅规则。

## 引用粒度

AI 根据资料生成的重要段落或独立结论，分别关联其依据的原文版本及具体位置。不仅在整页末尾列出参考资料，也不要求每句话分别标注来源。

采用该粒度以便核实具体结论，并为原始资料变化后定位受影响的知识内容提供依据。一个知识页的不同段落或结论可以关联不同来源。

## 证据随 Vault 携带

将 Vault 复制到另一台电脑后，知识页、引用关系及其引用的历史原文仍须完整可查。这些历史原文属于知识库的证据数据，需要随 Vault 携带。

未选择只在本机保存历史证据，以免迁移后只能查看当前资料，却无法核对形成知识时的原文。ADR-0003 规定的编辑历史是保存在本机应用目录的编辑辅助数据，其不可携带的生命周期不适用于这里的引用证据；ADR-0003 的编辑历史决策保持原有适用范围。

## 人工改写后的引用核验

用户修改带引用的结论后，保留原引用关联，但将修改后的段落标记为引用待核验。系统重新检查原文是否支持新说法；不支持时提示问题，保留用户正文，正文改写仍须用户确认。

未选择让旧引用自动继续有效，也未选择直接清除修改段落的引用，以同时保留人工修改与来源线索，避免将旧引用视为新说法已获支持的证据。引用待核验与正文修订待审阅是不同状态。

## 展示证据状态，不汇总结论置信度

展示出处、引用核验结果、冲突及待更新状态，不自动给结论生成统一的高／中／低置信度，也不让模型综合评分。引用核验检查原文是否支持某个说法，与独立判定该说法真实可靠区分。

本次知识库设计不沿用 ADR-0004 中按来源数量自动评级的规则。多份资料可能来自同一来源，数量增加不足以说明独立证据增加；明确展示证据和检查状态，更能表达系统实际检查过的内容。

## 来源移除不自动撤回知识

原始资料被删除或移出收录范围后，停止跟踪该资料，保留已有知识页与历史引用，并在检索证据中说明来源已移除。

未选择仅因来源被移除就自动为依赖该来源的结论提出撤回建议。移除资料不足以说明原有结论失效，资料整理与知识撤回应分别表达；移除来源本身也不表示其历史原文不支持原说法。

知识页修订待审阅时的检索边界见 ADR-0006；文件真源与可重建索引的存储边界见 ADR-0009。原文位置的具体表达、引用文件的具体格式及影响判定的具体算法，仍待后续技术设计细化。
