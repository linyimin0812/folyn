一个仓库，一套边界

Vault 是 Mochi 里数据隔离的最小单位。不同的项目、不同的知识领域，各自拥有独立的仓库，互不干扰，也互不共享——你决定什么放在一起，什么分开管理。

.vault本地存储多仓库
隔离管理
每个 Vault 都是一套独立的数据空间，笔记、附件、插件配置都各自存放，切换 Vault 就像切换一整套工作环境。
多仓库并存
工作、个人、团队项目可以拆分成多个 Vault 同时存在，在侧边栏之间快速切换，不必担心内容互相混淆。
本地优先
Vault 中的数据保存在本地设备上，不依赖云端账号即可正常使用，你对自己的数据拥有完整的控制权。
