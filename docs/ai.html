把 AI 代理，接进你的笔记里

Quill 不绑定单一模型厂商，而是把主流 CLI 代理直接适配进编辑器，你可以在写作和整理知识的同时，直接调用它们完成分析、生成与重构。

claude codecodex cligemini cliopencode
CLI 适配器
内置对以下 CLI 代理的适配支持，可直接在 Quill 中调用：Claude Code、Codex CLI、Gemini CLI、Opencode、Pi Code Agent、Qoder。
多模型厂商
支持多家大模型厂商，按任务需要或个人偏好自由切换，不被单一供应商绑定。
