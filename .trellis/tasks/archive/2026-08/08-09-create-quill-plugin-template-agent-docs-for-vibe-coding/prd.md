# create-folyn-plugin template: agent docs for vibe coding

## Goal

Make the plugin template generated by `create-folyn-plugin` ship with `AGENTS.md` (full) + `CLAUDE.md` (one-line pointer) so plugin authors can hand the scaffold to Claude Code / Codex / Cursor / other LLM agents and have enough context to vibe-code the plugin end-to-end without re-deriving the conventions each time.

## Decisions (locked)

* **Doc files**: `AGENTS.md` (full content, cross-tool standard) + `CLAUDE.md` (one-line pointer `See AGENTS.md.`). No content duplication.
* **Content depth**: rich. Sections: what this is, build/verify loop, first files to read, pitfalls, reference.
* **Placeholder substitution**: static. Doc is plugin-agnostic; agent reads `manifest.json` for name/id. No `filesToRewrite` change needed.

## Requirements

* Generated template contains `AGENTS.md` and `CLAUDE.md`.
* `AGENTS.md` covers: what a Folyn plugin is; build/verify loop (`pnpm install` → `pnpm build` → install `dist/` via Settings → Plugins → reload → test); first files to read (`manifest.json` contributes, `src/index.ts` entry, `build.mjs` React-external/single-file ESM/`dist/`-installable); key pitfalls (main-thread-only tray/window APIs per fix e43aed4; `manifest.main` rewrite `dist/` → `index.js`); reference pointer to external `folyn-plugin-sdk` repo + `folyn-plugin-plantuml` example.
* `CLAUDE.md` is one line pointing to `AGENTS.md`.
* Repo-root `AGENTS.md` (Trellis-managed) is the style precedent — short, pointer-heavy, no fluff.
* Doc is NOT added to `filesToRewrite` (static, plugin-agnostic).
* Smoke test (`test/smoke.mjs`) asserts both docs exist after generation.

## Acceptance Criteria

* [ ] `create-folyn-plugin demo-plugin --yes ...` produces `demo-plugin/AGENTS.md` and `demo-plugin/CLAUDE.md`.
* [ ] `AGENTS.md` contains the sections listed in Requirements.
* [ ] `CLAUDE.md` is a one-line pointer.
* [ ] Existing smoke assertions still pass.
* [ ] New assertion: both docs exist in generated dir.
* [ ] `pnpm build` on the `create-folyn-plugin` package succeeds; `pnpm test` passes.

## Definition of Done

* `pnpm build` + `pnpm test` green on `create-folyn-plugin` package.
* Smoke test updated to assert docs present.
* Commit on `master`.

## Out of Scope

* Rewriting the SDK API surface or authoring a full SDK reference (link out).
* Adding dev/watch mode to `build.mjs` (separate concern).
* Generating per-agent config files (`.cursor/`, `.codex/agents/`, etc.).
* Trellis scaffolding inside the generated plugin.
* Placeholder substitution in the docs.

## Technical Approach

* Add `template/AGENTS.md` with rich content (~60-100 lines, pointer-heavy style matching repo-root `AGENTS.md`).
* Add `template/CLAUDE.md` with one line: `See AGENTS.md.`
* No change to `src/index.ts` `filesToRewrite` — static doc.
* Update `test/smoke.mjs` to assert both files exist post-generation.

## Technical Notes

* Template dir: `packages/create-folyn-plugin/template/`.
* `filesToRewrite` allowlist in `src/index.ts:131-138` — unchanged.
* Repo-root `AGENTS.md` style precedent.
* Recent fix `e43aed4` (tray_set_enabled on main thread) is the kind of pitfall the doc should preempt.
