# 活动工作台原型：日历时间选择器

## Goal

将 folyn-activity-prototype.html 中"今天/本周/本月"按钮 + 前后翻页的时间选择，替换为一个日历弹层选择器，支持今日、本周、本月与任意日期区间。

## Requirements

- 日历图标按钮放在内容区头部右侧，与"时间线/实体关系"子标签同一行对齐
- 点击图标弹出日历弹层：
  - 快捷选项：今天 / 本周 / 本月
  - 月历网格：点击某天选择当天；再点另一天选择区间（起点 ≤ 终点，否则重置起点）
  - 月份前后翻页，不允许翻到 REF(2026-09-23) 之后
- 选中结果展示为按钮文案（周期标签），指标/时间线/日报路径随周期联动
- 非当前周期的数据继续使用 synthetic 合成数据（原型行为保持）
- 生成总结按钮保留，文案随周期变化（日报/周报/月报/总结）
- 移除旧的 range 按钮行与 period-nav 翻页行

## Acceptance Criteria

- [ ] 头部行：左侧时间线/实体关系子标签，右侧[生成总结][周期标签+日历图标]
- [ ] 日历弹层可选今天/本周/本月/单日/区间，选择后标签与数据刷新
- [ ] 区间选择：第一次点击高亮起点，第二次点击形成区间；反向点击重置起点
- [ ] 点击弹层外部关闭
- [ ] REF 之后日期置灰不可选

## Out of Scope

- 周选择列（点周头部选整周）、跨月区间拖拽
- 真实数据接入

## Technical Notes

- 单文件原型 folyn-activity-prototype.html，vanilla JS + 内联事件，与现有风格一致
